# P21.4 — High Density, Automatic Provisioning and P4 Bridge Correlation

## Status

**STATUS:** VALIDATED
**RESULT:** PASS

P21.4 valida, em execução local integrada, os três limites definidos para esta etapa:

1. alta densidade no runtime ns-3/Vanetza;
2. provisioning automático de credenciais por `vehId`;
3. integração real SUMO → P4 bridge → UDP 7400 → ns-3, com correlação semântica de eventos DENM.

P21.4 é independente da validação já fechada em P17. O cenário canónico P17 continua com oito veículos e não foi alterado.

Validation boundary

Esta validação demonstra integração operacional local entre:

SUMO
↕
P4 bridge
↕
UDP 7400
↕
ns-3
↕
Vanetza DENM

Não constitui validação de interoperabilidade externa com equipamentos, stacks ou C-ITS externos.

O simDuration=180 usado na execução integrada foi uma margem de processamento para permitir que a bridge terminasse a população SUMO de 60 s. Após a bridge concluir e a evidência necessária ser recolhida, o processo ns-3 residual foi terminado manualmente. Esta limpeza posterior não é apresentada como ns-3 EXIT=0; o EXIT=0 formal pertence ao teste dedicado de alta densidade.
